# ComfaBot 🤖
### Automatización inteligente para la gestión empresarial

## Descripción del proyecto
ComfaBot es un emprendimiento tecnológico de carácter académico enfocado en el desarrollo de soluciones que integran Inteligencia Artificial (IA) y Automatización Robótica de Procesos (RPA), con el propósito de optimizar actividades administrativas y documentales en las organizaciones.

## Objetivo
Desarrollar una solución tecnológica que integre IA y RPA para reducir tiempos operativos, minimizar errores manuales y mejorar la gestión de documentos empresariales.

## Servicios
- Automatización de procesos mediante RPA.
- Asistentes inteligentes con Inteligencia Artificial.
- Gestión y organización documental.
- Automatización de afiliaciones y novedades.
- Asesoría en transformación digital.

## Caso de aplicación
El proyecto toma como referencia un proceso de Comfamiliar Risaralda: la descarga, organización y radicación de certificados de afiliación en BrainManager.

La solución plantea las siguientes etapas:
1. Consultar la información del colaborador.
2. Descargar el certificado de afiliación.
3. Organizar los documentos por número de identificación.
4. Radicar los certificados en BrainManager.
